# 3-Minute Demo Script

## 0:00–0:30 — Problem

"Production incidents are repetitive, but incident-response teams often repeat the investigation from scratch. MemoryOps gives the response agent persistent organizational memory."

## 0:30–1:10 — Incident

Open an active Payment API incident. Show latency, error rate, Redis utilization, logs, and deployment information.

## 1:10–1:50 — Investigation

Click Investigate. Show the agent retrieving historical Hindsight memories. Highlight a previous incident with similar symptoms and its successful resolution.

## 1:50–2:25 — Recommendation

Show the agent's root-cause hypothesis, confidence, evidence, and recommended remediation. Explain that the recommendation combines current evidence with recalled historical experience.

## 2:25–2:45 — Resolution

Approve the remediation in the demo environment. Show metrics improving and the incident moving to RESOLVED.

## 2:45–3:00 — Learning loop

Show that the resolved incident is retained in Hindsight. Finish with: "The next time this pattern appears, the agent does not start from zero. It can recall what happened and what worked before."
